# Fruit Fun Adventure

Buatkan sebuah WEBSITE PEMBELAJARAN INTERAKTIF BERBASIS GAME untuk siswa kelas V sekolah dasar.

Nama website:

“FRUIT FUN”

English Vocabulary Adventure

Website ini digunakan sebagai media pembelajaran untuk penelitian pendidikan berjudul:

“Pengaruh Penerapan Website Latihan Kosakata Bahasa Inggris Berbasis Game terhadap Kemampuan Kosakata Siswa Kelas V di SDN Pasirlangu 1.”

Website harus benar-benar dapat digunakan oleh siswa untuk belajar kosakata Bahasa Inggris tema fruits, bukan hanya landing page atau mockup.

Jika suatu fitur belum mempunyai asset final seperti file gambar atau MP3, tetap buat struktur dan kode fungsionalnya serta gunakan fallback yang sesuai agar website tetap dapat dijalankan.

Pastikan setelah selesai tidak ada error JavaScript, broken button, broken navigation, atau halaman yang tidak dapat digunakan.
